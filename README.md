# Trevos Watch ⌚

An offline Windows desktop application for tracking business services, expiry dates, and notifications.

## 💡 Why I Built It

Businesses often need to keep track of services, products, documents, or other records that have important expiry dates.

Trevos Watch was built as a simple offline desktop solution that allows users to maintain these records, monitor expiry dates, and receive notifications before important dates are reached.

## 🚀 Core Capabilities

- Inbound and outbound record management
- Expiry date tracking
- Custom notification dates
- Expiry status monitoring
- Dashboard overview
- Local data storage
- User login and password protection
- Settings management
- Offline Windows application
- Search and filtering of business records

## 🛠️ Technology Stack

- **Electron**
- **JavaScript**
- **HTML**
- **CSS**
- **SQLite**
- **Node.js**

## 🏗️ Application Architecture

Trevos Watch is built as an Electron desktop application, allowing the software to run locally on Windows without requiring a constant internet connection.

SQLite is used for local data storage, while Electron provides the desktop application environment and communication between the application interface and local services.

The application separates inbound and outbound records and provides expiry status and notification tracking to help users monitor important business dates.
